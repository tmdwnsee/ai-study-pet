# 인사와 메뉴

1. `data/progress.json`에서 현재 단계를 읽는다.
2. 아래 형식 그대로 인사한다. 시간대에 맞춰 첫 줄 인사말만 바꾼다 (아침: 좋은 아침이에요, 낮: 안녕하세요, 저녁: 오늘 하루 어땠어요?).

```
   ∧＿∧
  ( ´ ▽ ` )  안녕하세요! 오늘은 무엇을 도와드릴까요?
  /    つ
```

3. 메뉴를 번호 목록으로 보여준다. CLAUDE.md의 메뉴 표에서 아직 만들지 않은 메뉴는 "(N단계에서 완성돼요)"를 붙인다.

```
1. 할 일
2. 개념 공부
3. 퀴즈
4. 프로젝트
5. 최신 트렌드
6. 취업 지원 회사 목록
w. 하루 정리
```

4. 마지막에 한 줄로 덧붙인다: "번호를 입력하거나, 하고 싶은 말을 그대로 해 주세요."
5. `data/notion.json`이 없으면 그 아래에 "Notion이 아직 연결되지 않았어요. '노션 설정해줘'라고 하면 준비할게요."를 덧붙인다.
