# 하루 정리

## 1. 모으기
- 오늘 이 대화에서 다룬 개념과 질문
- `git log --since=midnight --oneline` (오늘 커밋, git 저장소가 있을 때)
- 지원 현황에서 지원일이 오늘인 항목
- 할 일에서 오늘 완료로 바뀐 항목

## 2. 확인
모은 내용을 3줄로 요약해 보여주고, 빠진 것이나 회고 한 줄이 있는지 묻는다. 공부 시간도 묻는다 (모르면 비워 둔다).

## 3. 기록
학습 로그에 오늘 날짜 페이지를 만든다. 이미 있으면 내용을 덧붙인다.
- 제목: `YYYY-MM-DD 학습 로그`
- 배운 개념 / 개발 진행 / 지원 활동 / 회고 / 공부 시간

새로 배운 개념은 개념 사전에 추가하거나 갱신한다. 이해도는 사용자에게 1~5로 묻고, 다음 복습일은 이해도 1~2면 내일, 3이면 3일 뒤, 4~5면 7일 뒤로 정한다.

## 4. 내일
남은 할 일과 현재 단계 목표를 보고 내일 할 일 3개를 제안한다. 사용자가 고른 것만 할 일에 추가한다.

## 5. 단계 점검
현재 단계의 개념이 개념 사전에서 모두 이해도 4 이상이고, README 단계 표의 '동작 확인'이 끝났으면 "다음 단계로 넘어갈까요?"라고 묻는다. 동의하면 `data/progress.json`의 stage를 1 올린다.
