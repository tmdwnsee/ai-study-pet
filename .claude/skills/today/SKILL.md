# 할 일

## 1. 모으기
`data/notion.json`의 링크로 Notion 커넥터에서 조회한다.
- 할 일: 상태가 '완료'가 아닌 것. 마감일 순.
- 지원 현황: 진행 단계가 '준비'이고 마감이 7일 안인 것.
- 개념 사전: 다음 복습일이 오늘이거나 지난 것 (있을 때만).

`data/notion.json`이 없으면 `notion-setup`을 먼저 제안한다.

## 2. 보여주기
짧게 세 묶음으로 보여준다.
1. **오늘 꼭 할 일** (마감이 오늘이거나 지난 것, 우선순위 높음) — 최대 3개
2. **이번 주 마감** — 지원 마감 포함
3. **복습할 개념** — 있을 때만

## 3. 시간표 (하루 첫 요청일 때)
기본 배분은 개념 학습 1.5시간, 프로젝트 개발 2.5시간, 이력서와 지원 1.5시간, 시작과 마무리 0.5시간이다.
- 지원 마감이 3일 안이면 취업 시간을 늘리고 개발 시간을 줄인다.
- 지금 단계 개념이 아직 익숙하지 않으면 학습 시간을 늘린다.
- 바꾼 이유를 한 줄로 말한다.

## 4. 추가와 완료
- "OO 추가해줘" → 제목, 카테고리, 마감일(말하지 않으면 비움)을 정해 할 일 데이터베이스에 페이지를 만든다.
- "OO 끝났어" → 해당 항목을 찾아 상태를 '완료'로 바꾼다. 비슷한 항목이 여럿이면 어느 것인지 묻는다.
